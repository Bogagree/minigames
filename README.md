# MiniGames

RS School qualifying-stage project: a MiniGames SPA (Home, Library, Auth and Game Details dialogs) built with TypeScript, HTML and SCSS. No UI frameworks or ready-made UI libraries.

**Process:** [Spec-Driven Development](./docs/README.md) — specs, decisions, and conventions live in `docs/` and evolve with the code.

Story 1: repository setup, tooling, Home page layout, Auth dialog layout. See [docs/specs/story-1.md](./docs/specs/story-1.md).

- Local: `npm run dev` → http://127.0.0.1:5173/minigames/
- Preview: https://bogagree.github.io/minigames/
